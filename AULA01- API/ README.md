# Aula 01 - Introdução à IA

**Autora:** Ana Karina

## Objetivo

Registrar a primeira atividade da Residência em Tecnologias de IA Generativa utilizando Python e a API da OpenAI.

## O que foi desenvolvido

Nesta aula foi realizada a primeira integração com um modelo de Inteligência Artificial através de uma API.

## Aprendizados

- Como utilizar uma API Key.
- Como conectar uma aplicação Python com um modelo de IA.
- Como enviar uma pergunta para um modelo de linguagem.
- Como receber e exibir uma resposta gerada pela IA.
